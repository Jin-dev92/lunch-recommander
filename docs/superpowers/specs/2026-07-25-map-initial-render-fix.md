# 첫 방문 지도 초기 표시 수정

## 문제

기존 `Map` 컴포넌트는 Google Maps SDK와 현재 위치 좌표가 모두 준비된 뒤에만 지도를
생성했다. 위치 권한을 이미 허용한 재방문자는 좌표를 빠르게 받아 문제가 드러나지 않았지만,
첫 방문자는 권한 응답이나 OS 측위가 늦을 때 지도 영역이 빈 상태로 남았다.

## 변경

- Google Maps SDK가 준비되면 현재 위치를 기다리지 않고 서울 기본 좌표
  (`37.5665, 126.978`)와 축척 13으로 지도를 생성한다.
- 현재 위치가 없을 때 기본 좌표의 핀은 숨겨, 기본 좌표가 사용자의 선택 위치처럼 보이지
  않게 한다.
- 현재 위치가 도착하면 지도 중심과 축척을 갱신하고 핀을 표시한다.
- 지도 클릭이나 핀 이동으로 위치를 보정하는 기존 동작을 유지한다.
- 위치 권한 거부·타임아웃 시에도 기본 지도는 유지한다.

## 검증 기준

- Geolocation 응답이 오지 않아도 SDK가 준비되면 기본 지도가 생성된다.
- 현재 위치가 즉시 준비되면 기존처럼 해당 좌표와 축척 16으로 지도가 생성된다.
- 늦게 도착한 위치와 지도에서 보정한 위치가 검색 위치 콜백에 전달된다.
- 지도 SDK 실패, 권한 재요청, 검색 조건 동작에 회귀가 없다.

## 보안 영향

DB, RLS, RBAC, 인증, rate limit, 외부 API 키 전달 경로는 변경하지 않는다. 기본 지도
좌표는 공개 상수이며 민감 데이터나 사용량 데이터와 관계없다.
